# Moilya - Özel Tasarım Mobilya Web Sitesi

Moilya markası için modern, responsive tek sayfalık web sitesi.

## Özellikler

- **Ana Sayfa (Hero)** — Etkileyici giriş bölümü
- **Hakkımızda** — Marka hikayesi ve avantajlar
- **Koleksiyonlar** — Salon, yatak odası, yemek odası, mutfak, ofis
- **Süreç** — Danışmanlıktan teslimata 4 adım
- **Galeri** — Tamamlanan projeler
- **Müşteri Yorumları** — Otomatik dönen slider
- **İletişim** — Form ve iletişim bilgileri
- **Mobil uyumlu** — Tüm ekran boyutlarında düzgün görünüm

## Nasıl Açılır?

1. `index.html` dosyasını çift tıklayarak tarayıcıda açın
2. Veya VS Code / Cursor ile Live Server eklentisi kullanın

## Özelleştirme

| Dosya | Ne değiştirilir |
|-------|-----------------|
| `index.html` | Metinler, telefon, e-posta, adres |
| `styles.css` | Renkler (`:root` değişkenleri), fontlar |
| `script.js` | Form davranışı, animasyonlar |

### Renk paleti

- Arka plan: `#faf8f5` (krem)
- Vurgu: `#8b6914` (altın/bronz)
- Koyu: `#1a1814` (siyah-kahve)
